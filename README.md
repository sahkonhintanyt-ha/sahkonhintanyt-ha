# ⚡ Sähkön hinta nyt

Finnish spot electricity price (pörssisähkö) – free data, free API and a free Home Assistant integration.

- 🌐 **Website:** [sähkönhintanyt.org](https://sähkönhintanyt.org/) – today's and tomorrow's prices, monthly averages and an electricity company comparison
- 🏠 **Home Assistant:** [sahkon-hinta-nyt-ha](https://github.com/sahkonhintanyt-ha/sahkon-hinta-nyt-ha) – in the HACS default list, with a built-in price card and ready-made blueprints
- 🔌 **Free API:** [api.sähkönhintanyt.org](https://sähkönhintanyt.org/integraatiot/) – no key, no registration, CORS enabled
- 💬 **Community:** [Home Assistant forum thread](https://community.home-assistant.io/t/finnish-spot-electricity-price-porssisahko-cheapest-hours-switch-price-alert/1027594)

Data: ENTSO-E / Nord Pool day-ahead, 15-minute resolution, VAT 25.5 % included.
